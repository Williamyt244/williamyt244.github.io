📚 Como Usar

Guia completo para gerenciar seu portfólio

1

Hospedar Imagens

Use o Imgur (imgur.com) para hospedar suas imagens gratuitamente. Faça upload e copie o link direto da imagem.

Acessar Imgur
2

Adicionar Portfólio

Na aba "Portfólios", clique em "Novo Portfólio", preencha os dados e salve. O JSON será gerado automaticamente.

3

Atualizar o GitHub

Copie o JSON gerado → vá ao GitHub → abra portfolios.json → clique no lápis ✏️ → cole o conteúdo → Commit changes.

4

Aguardar Publicação

Após salvar no GitHub, aguarde 1 a 3 minutos e as alterações aparecerão no site automaticamente.

5

Alterar Senha

Para mudar a senha do painel admin, abra o arquivo admin.js no GitHub e edite a linha com SENHA_ADMIN.

6

Link Discord no site

Vá em Configurações, coloque seu username do Discord e gere o JSON. Atualize o portfolios.json no GitHub.
